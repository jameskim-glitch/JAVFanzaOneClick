# JAV FANZA OneClick

Stash용 한국어 메타데이터·표지·배우 사진·제작사 로고·폴더 태그 플러그인입니다.
공개 준비 버전: **1.12.0**. 기존 개인 설치본과 분리해 개발합니다.

## 기능

- FANZA 작품 정보와 표지를 조회하고 한국어 제목·설명을 정리합니다.
- StashDB 및 FANZA에서 배우 사진과 제작사 로고를 조회합니다.
- 기존 영문 별명으로 배우를 조회하고, 확인 가능한 제작사 연결을 정리합니다.
- 기존 SubtitleCat 자막을 검색·다운로드합니다. 새 자막을 생성하지 않습니다.
- 새 장면의 폴더 이름과 정확하게 일치하는 **기존 태그**를 자동 추가합니다.
- 기존 장면의 폴더 태그 누락 검사·백업 후 채우기를 제공합니다.

## 설치

Windows x64용 설치 파일을 사용하는 구성이 기본입니다. Python으로 실행하려면
별도의 의존성 설치와 플러그인 실행 명령 변경이 필요합니다.

1. 배포된 설치 프로그램을 실행하거나, 빌드된 `JAVFanzaOneClick` 폴더를
   `%USERPROFILE%\.stash\plugins` 아래에 넣습니다.
2. Stash의 **Settings → Plugins → Reload Plugins**를 누릅니다.
3. 브라우저를 새로고침합니다.

일반적인 사용법과 기존 버전의 기능은 [한국어 설명서](README_KO.md)를 확인하세요.
StashDB 기능은 사용자가 자신의 StashDB 연결과 API 키를 설정해야 합니다.
API 키, Stash 설정 파일, DB, 캐시, 영상 및 실제 라이브러리 기록은 배포하지 않습니다.

## 1.12.0의 품번 조회 변경

외부 확장 프로그램의 제작사별 변환표를 포함하지 않습니다. 일반적인 품번 형식으로
제한된 후보를 만들고, FANZA가 반환한 실제 콘텐츠 ID와 품번을 비교합니다.
제목만 비슷한 결과나 식별번호가 모호한 결과는 자동 선택하지 않습니다.

제작사별 예외 규칙·별도 접미사·Blu-ray 전용 품번 변환을 추측하지 않으므로,
기존 변환표 방식과 모든 품번에서 동일한 검색률을 보장하지 않습니다.
검색되지 않는 작품은 원본 품번과 출처를 직접 확인하세요.

## 개발 및 테스트

Python 3.12와 Node.js가 필요합니다. 사용자 Stash를 켜지 않아도 기본 테스트가 가능합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m unittest discover -p "test_*.py"
node --test test_alias_ui.cjs test_duplicates_ui.cjs test_hq_ui.cjs test_subtitles_ui.cjs
```

일부 외부 사이트 통합 테스트는 기본적으로 건너뜁니다. 기본 테스트의 GraphQL 변경은
임시 메모리 서버에만 적용되며 사용자 라이브러리를 수정하지 않습니다.

## Windows 빌드

```powershell
python build.py
```

결과는 `dist/1.12.0/`에 생성됩니다. 소스와 실행 파일을 섞어 배포하지 마세요.
새 빌드를 배포하기 전에 실행 파일 프로토콜 테스트와 격리된 설치 테스트를 수행하세요.
소스 공개와 별개로 배포 라이선스 정책은 저장소 소유자가 지정해야 합니다.

## 안전 및 개인정보

- 관리 작업 전 백업하세요. 일부 일괄 변경은 Stash의 전체 백업을 먼저 생성합니다.
- 태그 채우기·병합 중에는 스캔, 다른 일괄 작업, 수동 편집을 동시에 실행하지 마세요.
- 인터넷에 인증 없이 Stash를 공개하지 마세요. 로컬 전용 또는 인증된 비공개 접속을 사용하세요.
- 로그를 공개할 때 파일 경로·키·쿠키·실제 라이브러리 정보를 제거하세요.
- 외부 서비스의 변경, 접근 정책, 계정 권한에 따라 조회가 실패할 수 있습니다.
- 본 프로젝트는 Stash, StashDB, FANZA/DMM, SubtitleCat의 공식 제품이 아닙니다.
  메타데이터·이미지·자막 자체의 권리는 각 권리자에게 있습니다.
